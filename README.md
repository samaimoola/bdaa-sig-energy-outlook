Coal and clean energy analysis for the BDAA x SIG Invitational 2026.

# The Transition Has Two Speeds
## Coal vs. Clean Energy

Advanced Track submission for the BDAA x SIG Invitational 2026.

**Team members:** Samai Moola, Gowtham Senthilkumar, Sanjay Subapathy

**Presentation video:** https://youtu.be/YrkcxFQtx24

## Project overview

We examine how electricity demand and clean generation growth relate to fossil generation, then use U.S. coal consumption and generation data to develop an industry investment outlook.

Our recommendation is overweight clean electricity generation and neutral U.S. thermal coal over a 24–36 month horizon.

## Data sources

- Provided Ember country electricity dataset, 2020–2025.
- Provided EIA U.S. coal consumption and quality dataset, 2020–2025.
- Additional EIA annual state generation dataset: https://www.eia.gov/electricity/data/state/

## How to run

1. Download this repository’s files.
2. Open `Energy_Outlook.ipynb` in Google Colab.
3. Upload the three CSV files when prompted.
4. Run the cells from top to bottom.

The notebook generates charts, supporting tables, and a downloadable results ZIP.

## Methodology and limitations

We compare the same 91 countries across 2020–2025 and use the U.S. Electric Power sector for national coal comparisons. We avoid overlapping totals and preserve missing values.

The scenario analysis uses stated assumptions. Historical generation trends do not establish causation or guarantee investment returns.
